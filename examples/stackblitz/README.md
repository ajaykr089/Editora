# Editora: React quick start

The smallest working setup for [Editora](https://github.com/ajaykr089/Editora): React, Vite and the lite plugin set.

[Open in StackBlitz](https://stackblitz.com/github/ajaykr089/Editora/tree/main/examples/stackblitz?file=src/App.jsx)

Run it locally:

```bash
npm install
npm run dev
```

Everything that matters is in `src/App.jsx`: pick plugins, pick toolbar items, render `EditoraEditor`.
