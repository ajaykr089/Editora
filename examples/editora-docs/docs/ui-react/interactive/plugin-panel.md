# PluginPanel

The `PluginPanel` component is used for plugin-side controls in editor layouts.

## Basic Usage

```tsx live
function Example() {
  return (
    <ThemeProvider>
      <PluginPanel>Plugin settings</PluginPanel>
    </ThemeProvider>
  );
}
```
