# Toggle

```tsx live
function ToggleDemo() {
  return (
    <ThemeProvider>
      <Toggle variant="minimal" tone="brand" pressed>
        Pin
      </Toggle>
    </ThemeProvider>
  );
}
```

## Supported Props

`pressed`, `disabled`, `loading`, `headless`, `size`, `variant`, `tone`, `shape`, `elevation`, `name`, `value`, `required`, `iconOn`, `iconOff`, `onInput`, `onChange`
