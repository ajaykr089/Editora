## Element: `<ui-pagination>`

Pagination renders the `ui-pagination` custom element from `@editora/ui-core`, which can also be used without React.

**Attributes:** `aria-label`, `count`, `headless`, `href-template`, `page`, `size`, `variant`

**Events:** `change`
