## Props

| Prop | Type | Description |
| --- | --- | --- |
| `alignTop` | `boolean` | Messages sit at the top instead of the bottom while the transcript is short. |
| `anchorPeek` | `number` | Pixels of the previous message kept visible above a new turn. |
| `autoScroll` | `boolean` | Do not follow new content at the end. |
| `busy` | `boolean` | Hold screen-reader announcements while a reply streams. |
| `hideJumpButton` | `boolean` |   |
| `initialScroll` | `'end' \| 'start' \| 'last-anchor'` |   |
| `jumpLabel` | `string` |   |
| `label` | `string` | Names the scrollable region (default "Messages"). |
| `onFollowChange` | `(following: boolean) => void` |   |
| `onReachStart` | `() => void` | The reader is near the top: load older messages. |

Also accepts the standard HTML and React props of the element it renders (`className`, `style`, `id`, `aria-*`, `data-*`, event handlers).

## Element: `<ui-message-scroller>`

MessageScroller renders the `ui-message-scroller` custom element from `@editora/ui-core`, which can also be used without React.

**Attributes:** `busy`, `label`, `no-auto-scroll`

**Events:** `follow-change`, `reach-start`
