# Spinner API

```tsx
import { Spinner } from '@editora/ui-react';
```

## Props

| Prop | Type | Description |
| --- | --- | --- |
| `decorative` | `boolean` | Hide it from assistive technology when the surrounding control already says it is busy. |
| `label` | `string` | What is loading, read by screen readers (default "Loading"). |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| number \| string` | A named size or a CSS length (a number is px). |
| `speed` | `'slow' \| 'normal' \| 'fast'` |   |
| `tone` | `'current' \| 'brand' \| 'neutral' \| 'success' \| 'warning' \| 'danger'` |   |
| `variant` | `'ring' \| 'dots' \| 'bars'` |   |

Also accepts the standard HTML and React props of the element it renders (`className`, `style`, `id`, `aria-*`, `data-*`, event handlers).

## Element: `<ui-spinner>`

Spinner renders the `ui-spinner` custom element from `@editora/ui-core`, which can also be used without React.

**Attributes:** `decorative`, `label`, `size`, `variant`
