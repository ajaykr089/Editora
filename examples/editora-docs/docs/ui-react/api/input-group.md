## Props

| Prop | Type | Description |
| --- | --- | --- |
| `borderlessRows` | `boolean` | No rule between the control and top/bottom rows. |
| `disabled` | `boolean` | Disables the control inside. |
| `invalid` | `boolean` | Marks the group and its control invalid. |
| `size` | `'sm' \| 'md' \| 'lg'` |   |

Also accepts the standard HTML and React props of the element it renders (`className`, `style`, `id`, `aria-*`, `data-*`, event handlers).

## Element: `<ui-input-group>`

InputGroup renders the `ui-input-group` custom element from `@editora/ui-core`, which can also be used without React.
