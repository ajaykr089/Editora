'@editora/paste-cleaner': minor

New package: cleans pastes from Word, Word for the web, Google Docs, Google Sheets, Excel, Pages/TextEdit, web pages and VS Code into semantic HTML with real nested lists, headings and header rows, converts Markdown and plain text, and sanitizes against an allow-list. Includes `attachPasteCleaner()` for any contenteditable and an Editora plugin.
