Tailwind CSS support: `@editora/ui-core/tailwind` (a Tailwind v3 preset) and `@editora/ui-core/tailwind.css` (Tailwind v4) map Editora's theme tokens to Tailwind colours (`bg-ui-surface`, `text-ui-muted`, `bg-ui-chart-1` …), radius, fonts and shadows, so Tailwind-styled markup and the components share one theme. Adds state variants (`ui-open:`, `ui-disabled:`, `ui-invalid:` …) and, in v3, `part-[name]:` for styling a component's parts. See the new "Tailwind CSS" theming guide.
