# Underline plugin

> [!IMPORTANT]
> **Live Website:** https://editora-ecosystem.netlify.app/  
> **Storybook:** https://editora-ecosystem-storybook.netlify.app/

Underline formatting for the selected text.

This plugin is part of [`@editora/plugins`](https://www.npmjs.com/package/@editora/plugins) and is not published on its own.

## Installation

```bash
npm install @editora/plugins
```

## Usage

```ts
import { UnderlinePlugin } from "@editora/plugins";

const plugins = [UnderlinePlugin()];
```

## Command and shortcut

- Command: `toggleUnderline`
- Shortcut: `Mod-u`
